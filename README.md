🍽 Heaven's_Kitchen – Responsive Restaurant Website Project

A fully functional, visually appealing restaurant website built using HTML and CSS, with a strong focus on responsive design, clean layout, and user experience. Designed to simulate a real-world restaurant interface with modern web development practices.

📌 Features

Feature	Description
🏠 Hero Section	Stunning full-screen landing section with welcoming message
📖 Menu Showcase	Category-wise display (Breakfast, Lunch, Dinner) with pricing and images
🧑‍🍳 About Section	Clean introduction to the restaurant and values
📸 Gallery	Beautiful image grid showcasing dishes and ambiance
📞 Contact Section	Social links (Instagram, Facebook) + contact form (static)
🔗 Smooth Navigation	Header links scroll directly to respective sections
📱 Responsive Design	Fully mobile-optimized using media queries
🎨 Stylish UI/UX	Font, color scheme, and spacing optimized for readability and aesthetics
🧩 Scalable Structure	Easy to extend with JavaScript or backend frameworks later
🛠️ Tech Stack

Languages: HTML5, CSS3
Tools: VS Code, GitHub
Design Approach: Mobile-First, Clean Code, Modular Styling
